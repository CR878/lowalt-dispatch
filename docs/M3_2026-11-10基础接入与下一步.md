### 重要运行语义

- `M2Tools`的A*适配只使用现有几何基线。独立校验拒绝后，如果基线无法根据反馈改线，明确阻止下发；不能宣传“动态避险改线已经完成”。
- 任务预算使用已知的`initial_energy_wh - reserve_energy_wh`作为上限，消耗由M2独立复算；不另造一套机型或能耗模型。
- `M2Tools.verify_route()`对带当前遥测的请求明确抛出`NotImplementedError`。现有校验器并不支持剩余路线复核，不能给旧报告换个时间戳冒充已复核。
- `TaskService.run()`先向台账占用`(run_mode, task_id)`，再运行决策。占用提交后中断，不自动释放或重新开始；用原审计恢复。
- 台账只拥有M3运行记录`m3_task_runs`，不另建M5的业务任务模型。M5可通过`TaskService`引用运行状态。
- 本地审计必须保存到稳定磁盘目录。当前设计面向单个编排实例/持久目录；迁移到另一台ECS时必须同步原日志，不能仅凭RDS记录恢复已丢失的日志。
- 当前版本仍为每个任务一次运行、内部最多有限次规划。已接受任务的后续环境事件重规划，需要M2动态规划和M4当前状态接口共同接入；不要换日志对同一任务重新`run()`。
- 数据库结果保存失败不抹除先前占用和本地审计；恢复读取旧命令，不重新调用工具。
- Redis、OBS同步失败只返回`sync_errors`，不能改变已下发命令结果。`service.sync(record)`可重试；当前没有后台自动同步进程。
- MQTT QoS1可能重复投递。边缘执行端必须在持久存储里按`command_id`去重。MQTT PUBACK不是飞控ACK。
- ACK超时后，云通道仍可接收原命令ACK；进程重启后用`watch_command()`恢复监听，不重新发布。
- MQTT事件由`drain_events()`交给应用处理：ACK交给`TaskService.recover()`，遥测交给对账/本地决策，心跳接收时间交给链路策略。当前没有常驻消息分发进程。
- `confirm()`的摘要防止用户确认旧草稿。用户身份认证、确认按钮和权限由M5实现，摘要本身不是电子签名。

## 3. 现在直接运行，不需要任何华为云账号

PowerShell进入仓库根目录：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-m3.txt
.\.venv\Scripts\python.exe -m agent.integration check
.\.venv\Scripts\python.exe -m agent.integration demo --scenario S1-01
.\.venv\Scripts\python.exe -m agent.integration demo --scenario S2-01
.\.venv\Scripts\python.exe -m pytest
```

预期：

- `check`输出`network_contacted: false`，本地默认不要求云密钥。它只检查所选配置的完整性，不证明网络和服务可用。
- S1-01：真实调用现有M2计算代码，合成机型参数、MOCK执行回执；`acknowledged`，重复请求仅提交一次。
- S2-01：真实独立校验器发现限制区问题；基线无法改线，`blocked`，提交次数0。
- 每次演示在`logs/agent/integration/<批次>/`产生SQLite台账、`*_MOCK.jsonl`、本地归档和`summary_MOCK.json`。

合成参数沿用`validator.__main__`已有的明确标识演示参数，未写入机型配置，不能作为安全效果指标。

没有模型时先创建空草稿：

```powershell
.\.venv\Scripts\python.exe -m agent.integration draft --text "送一份药品到医院，电池80%"
```

目的地坐标和能量Wh保持未知；缺信息就补，不把SOC自动换算成Wh。

## 4. 云资源就绪后，只做配置和联调

复制`.env.example`为`.env`，填写真实值。CLI只有显式传`--env-file .env`才读取文件；系统环境变量优先。
不要提交`.env`、私钥或凭据。

| 要启用什么 | 设置 |
|---|---|
| RDS | `M3_LEDGER_BACKEND=rds`、`RDS_DSN=postgresql+psycopg://用户:URL编码密码@内网地址:5432/数据库`；按实例要求添加TLS参数和CA |
| DCS | `M3_CACHE_BACKEND=redis`、`DCS_HOST`、`DCS_PORT`、`DCS_PASSWORD`、按实际实例设置`DCS_TLS` |
| OBS | `M3_ARCHIVE_BACKEND=obs`、`OBS_ENDPOINT`为HTTPS、`OBS_BUCKET`、授权凭据；支持临时安全令牌 |
| MaaS | `MAAS_CHAT_ENDPOINT`完整请求地址、`MAAS_API_KEY`、`MAAS_MODEL`；具体字段兼容性须在开通后验证 |
| MQTT | 地址、端口、每客户端账号、TLS及CA；`M3_VEHICLE_ID`必须与执行端约定一致 |
| 非MOCK工具 | `M3_RUN_MODE=integration`；此标识不等于实飞，SITL对象继续带`is_simulated=True` |

```powershell
.\.venv\Scripts\python.exe -m agent.integration --env-file .env check
# 以下命令会调用模型、可能产生费用，但不规划或下发：
.\.venv\Scripts\python.exe -m agent.integration --env-file .env draft --text "明确的任务文字" --use-maas
```

后端调用范例（需M5接入）：

```python
settings = M3Settings.from_env()
repository = settings.make_repository()
repository.initialize()  # 显式建立M3台账，构造对象时不会连接数据库
channel = settings.make_mqtt_channel()
channel.start(settings.mqtt_host, settings.mqtt_port)
tools = M2Tools(scene, snapshot_provider, channel.submit_command, profile=profile, is_mock=False)
service = TaskService(tools, repository, settings.audit_dir,
                      projection=settings.make_projection(), archive=settings.make_archive())
record = service.run(confirmed_task)
```

接口和CLI都不会创建ECS/RDS/DCS/OBS等云资源。

`run`命令要求完整Task、RiskSnapshot、机型文件以及`--allow-dispatch`；当前使用固定v0虚拟城区，不能拿真实城区坐标直接运行。

```powershell
.\.venv\Scripts\python.exe -m agent.integration --env-file .env run --task-file task.json --snapshot-file snapshot.json --profile-file scenarios/vehicles/placeholder.yaml --vehicle-key placeholder --allow-dispatch
```

当前机型文件未填齐，因此此命令应失败，不会猜参数。示例只说明后续入口，不代表现在已经联通。

恢复原任务，绝不重发原命令：

```powershell
.\.venv\Scripts\python.exe -m agent.integration --env-file .env recover --task-id 实际任务ID
.\.venv\Scripts\python.exe -m agent.integration --env-file .env recover --task-id 实际任务ID --wait-mqtt
```

`--ack-file`只导入执行适配层实际收到并保存的ACK。恢复时必须使用原台账和原审计目录。恢复占用仍活跃的日志会被锁拒绝。

## 5. 执行端需要对齐的消息协议

主题前缀：`lowalt/v1/{mock或integration}/vehicles/{vehicle_id}`。

| 后缀 | 方向 | body |
|---|---|---|
| `commands` | 云→边 | 公共`PlanCommand` |
| `acks` | 边→云 | 公共`PlanAck`，包含实际任务/命令ID/执行版本 |
| `telemetry` | 边→云 | `ExecutionObservation`，包含任务ID、关联命令ID和`VehicleState` |
| `heartbeat` | 边→云 | `{"sequence": 递增非负整数}`；上层使用本地接收时间 |

统一外层：`schema_version=m3-message-0.1`、`kind`、`run_mode`、带时区`sent_at`、`body`。
命令和ACK使用`retain=false`。测试/真实接入命名空间分离。
执行端要在过期拒绝、去重、飞控接受后生成ACK等行为上与M4约定，云侧代码不能替代这些实现。
