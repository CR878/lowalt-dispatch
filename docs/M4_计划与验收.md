# M4 执行端：计划与验收（2026-11-11）

## 0. 一句话

把 `edge/` 从"README 占位"变成**能收命令、能去重、能拒过期、能出 ACK、能产遥测、能重启恢复**的执行端；
真实 PX4 SITL 接入层写出来，但**本轮不声称已实测**——环境不具备。

## 1. 为什么这一轮跑不了 SITL

| 条件 | 现状 |
|---|---|
| Docker daemon | 未启动（`dockerDesktopLinuxEngine` 管道不存在） |
| `wsl.exe` | 被本机安全策略拦截，无法起 WSL 后端 |
| PX4 固件 / Gazebo | 仓库里没有，机器上未确认安装 |
| `mavsdk` Python 包 | 未安装，`requirements*.txt` 里没有 |
| 机型参数 | `scenarios/vehicles/placeholder.yaml` 全 `null` |
| ENU 原点 | `docs/接口契约.md` 标注"未定" |

所以本轮的验收对象是**控制流与契约**：命令进来之后怎么判、怎么记、怎么回、怎么恢复。
**不是**"飞起来了"，也**不是**"PX4 在环通过"。

## 3. 写死的语义（测试守着）

1. **去重**：同一 `command_id` 只执行一次。重复投递（MQTT QoS1 可能重复）返回**原来那条 ACK**，不重新执行。
2. **内容冲突**：同一 `command_id` 携带不同 `task_id`/`plan_version`/`payload` → 拒绝并记审计，不覆盖原记录。
3. **过期**：`now >= expires_at` → `accepted=false`，`reject_reason="expired"`，不执行。
4. **未来命令**：`now < issued_at` → 拒绝（`not_yet_valid`）。
5. **任务一致性**：ACK 的 `task_id`/`plan_version` 必须与命令逐字一致。
6. **ACK 不等于完成**：`accepted=true` 只表示"执行端接下了"，`fc_mode` 是飞控模式原样透传，不能解释为"已送达"。
7. **遥测**：每条 `ExecutionObservation` 必须带 `task_id`、`accepted_command_id`、`state.executing_plan_version`；`provenance.is_simulated=True`（SITL / Fake 都算仿真）。
8. **坐标**：`Position.frame=enu_m` 不下发给真实 MAVSDK——ENU 原点未定，转换就是猜。`MavsdkExecutor` 遇到 ENU 直接 `NotImplementedError` 并指向契约文档。
9. **断连**：复用 `agent/link.py` 的 `CloudLinkMonitor` 判云端链路；断连时**不重发命令、不改飞控模式**，只允许按已缓存且仍有效的方案执行。这是"本地备用方案切换"，不是"边缘实时重规划"。
10. **恢复**：进程重启后，已接受但未完成的命令从 SQLite 读回，**不重新执行**，进入 `recovering` 状态等对账。

## 4. 验收命令与预期

```bash
# 1. 全量测试
.venv/Scripts/python.exe -m pytest -o addopts="" -q
# 预期：原有 174 passed / 3 skipped + 新增 edge 用例全绿

# 2. 离线 demo（不连 MQTT、不连飞控）
.venv/Scripts/python.exe -m edge.demo --scenario S1-01
# 预期：打印 accepted ACK、遥测序列长度、落库路径；输出带 MOCK 标注

# 3. 重复投递
.venv/Scripts/python.exe -m edge.demo --scenario S1-01 --duplicate
# 预期：第二次返回同一条 ACK，execution_count 仍为 1

# 4. 过期命令
.venv/Scripts/python.exe -m edge.demo --scenario S1-01 --expired
# 预期：accepted=false, reject_reason=expired，execution_count=0

# 5. 静态检查
.venv/Scripts/python.exe -m ruff check edge tests
.venv/Scripts/python.exe -m ruff format --check edge
```

## 5. 非目标（本轮明确不做）

- 不接真实 MQTT（离线 demo 直接调 `EdgeService`；MQTT 适配留给联调，`agent/messaging.py` 的客户端侧契约已就位）
- 不起 PX4 SITL、不装 Gazebo、不装 `mavsdk`
- 不做真机、不做 MAVLink 抓包
- 不做"边缘实时重规划"（那需要 M2 动态规划 + 当前状态校验，仍缺）
- 不改 `core/models.py`、`agent/` 的既有语义

## 6. 阻塞项（需要 A 提供）

| 阻塞 | 影响 |
|---|---|
| 机型参数（`placeholder.yaml` 全 null） | 能量/备降用例只能跑合成参数 |
| ENU 原点 + 高度基准 | ENU→WGS84 转换无法实现，真实 MAVSDK 只能收 WGS84 航点 |
| `velocity` 用 NED 还是 ENU | 遥测速度字段只能原样透传，不能换算 |
| PX4 固件版本 | SITL 镜像/版本无法固定 |
| Docker daemon 可启动 | 才能跑 `tests/test_m3_external.py` 和后续 SITL 容器 |
