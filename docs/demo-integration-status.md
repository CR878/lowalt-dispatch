# 竞赛演示整合状态

适用范围：离线竞赛演示。配合 [AGENTS.md](../AGENTS.md) 和 [视频路线](demo-video-roadmap.md) 阅读。原有任务 API、真实地理预览、飞控执行边界和事实记录均独立保留。

## 演示入口

在 `apps/console` 安装锁定依赖（`npm ci`），启动 `npm run dev`，浏览器访问 `/demo`。首页也提供“观看竞赛演示”入口。不需要 Python 后端、账户、地图服务或云资源。生产部署应提供 SPA 路由回退。

确认示例工单后，播放三分钟情景。可以暂停、拖动时间轴、点击章节或已发生事件进行重拍。录制模式隐藏控制栏，Escape 恢复；重置后回到未确认状态。影片中的模型、地点、动画和状态均为演示素材，算法说明是概念示意，不是此次运行的规划结果。

## 可核查验证

- `npm run test:demo`：工单确认、章节边界、通信状态、终态与回放时间一致性。
- `npm run build`：TypeScript 与打包检查。
- 浏览器检查 `/demo`：离线工单确认、模型加载、时间轴、异常情景、复盘、暂停和重置。
- 新增 `tests/demo.spec.ts` 作为控制台浏览器回归。CR30 使用随 Three.js 打包的本地 Draco 解码资源，模型加载可通过 `data-model=loaded` 检查。

本轮本机检查：回放单元测试 2/2 通过、TypeScript 检查通过、Vite 生产构建通过（本机使用 `--configLoader runner` 处理 Windows 沙箱下默认配置加载器无法访问上级目录的问题）。Chrome 对生产预览执行实际模型加载、工单确认、118 秒异常切换、复盘和重置检查，未观察到页面异常或外网 HTTP 请求。完整旧业务回归与最新算法评测尚未重跑。

## 虚构滨水城市视觉升级（2026-11-23）

- 视觉风格：蓝调微缩数字孪生，暖色窗灯、冷色玻璃、层次化地块与真实感道路纹理。
- 城市由固定的艺术布局生成 51 栋建筑，包含办公、住宅和仓储三类轮廓，以及河岸、公园、桥梁、街道路口、屋顶设施和绿化。
- 建筑与附属细节按材质批量实例化；固定灯光的阴影仅更新一次。无需额外在线贴图或地图服务。
- 摄影机通过已有回放时间轴选择视觉机位，暂停和跳章具有确定性。三维场景的建筑与位置均为虚构美术元素，未接入真实规划、坐标或飞控。
- 新增城市布局回归用例，以及浏览器中的城市资产加载断言。布局生成逻辑已检验为 51 栋可重复生成的多类建筑；当前工作环境未能启动本地完整构建与浏览器，因此最终视觉与性能需以 CI 和实际录屏机验收为准。上方测试结果属于先前整合版。

独立视觉验收工作流：[AERIS offline city visual](https://github.com/Gindama713/lowalt-dispatch/actions/workflows/demo-visual.yml)。无需启动 Python 服务，单独执行回放测试、前端构建、Chromium 浏览器断言和画面截图。原控制台工作流的后端格式检查与此验收独立。
