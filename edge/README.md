**负责人：A（与 C 配合）**　**状态：⬜ 目录占位，无代码**

## 职责

云端与飞控之间的那一层。三件事：

1. 接收并缓存云端下发的任务版本与**已校验**的备用方案；
2. 用 MAVSDK/MAVLink 把任务交给飞控，收 ACK，回传遥测；
3. 云端链路失效时，只用本地缓存里**仍有效**的数据做决定：继续 / 切换备用方案 / 返航 / 备降。

## 命名的分寸

- 从预校验的备用路线里选一条执行 → **"本地备用方案切换"**
- 断连后按当前状态重新算并重新校验一条新路线 → **"边缘实时重规划"**

本月做哪一级就说哪一级。**做不到实时重规划却这么叫，是最容易被问穿的地方。**

## 第一个任务（11/15—11/18）

1. 独立进程启动，连 Mosquitto 的 `cloud_link`，连飞控的 `flight_control`。
2. 收到 `PlanCommand` 后校验 `expires_at` 和 `command_id` 去重，再转 MAVSDK。
3. 把收到的 `(task_id, plan_version, snapshot_id)` 落本地文件 —— 断连时读这个。
4. 断连判定阈值写进配置，**并实测记录**检测时延与恢复时延（交付要报这两个数）。
